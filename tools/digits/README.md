# Сеть для рукописных цифр («По фото», 2.43)

Маленькая свёрточная сеть (`js/route-digits.js`) узнаёт цифры, вписанные синей ручкой в маршрутный лист.
Работает только в телефоне. Эта папка на сайт не выкладывается.

1. Скачать 4 файла MNIST (`train-images-idx3-ubyte.gz`, `train-labels-idx1-ubyte.gz`, `t10k-images-idx3-ubyte.gz`,
   `t10k-labels-idx1-ubyte.gz`) в эту папку. MNIST — Y. LeCun, C. Cortes, C. Burges, лицензия CC BY-SA 3.0.
2. `python3 train.py 9` — обучение (numpy, ~8 минут); 11-й класс — «не одна цифра» (две слитные цифры или половинка).
3. `python3 export.py ../../js/route-digits-w.js` — веса в int8.

Фото маршрутов людей для обучения не используем и в репозиторий не кладём (ФИО, табельные номера).
