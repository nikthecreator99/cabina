# Магазин CABINA

В каталоге сайта /data/shop.html доступны цены, контакты, оферта и политика без приглашения. Для покупки нужен действующий аккаунт. Для проверки закрытой части создайте обычный аккаунт модератора через приглашение.

Сервис запускается из server/stack/docker-compose.yml и Caddyfile. В папке стека разместите каталог server/shop как shop, а data/shop-catalog.json как shop-catalog.json. Создайте постоянную папку shop-data, доступную на запись пользователю 1000:1000. Храните резервные копии SQLite через sqlite3.Connection.backup(), в том числе перед переносом сервера. Существующая копия PostgreSQL не включает заказы магазина.

В настройках магазина Робокассы выберите SHA256. ResultURL — https://api.cabina-app.ru/shop/v1/result (POST). SuccessURL и FailURL — https://cabina-app.ru/data/shop.html (GET). В «Мой налог» подтвердите права для Робочеков СМЗ. Проверяйте вручную в личном кабинете возврат денег и аннулирование чека. После подтверждённого полного возврата выполните в папке стека команду с номером счёта Робокассы:

    docker compose exec shop python -B server.py record-refund НОМЕР

В окружении контейнера задайте ROBOKASSA_LOGIN, ROBOKASSA_PASSWORD1 и ROBOKASSA_PASSWORD2. Пара паролей должна соответствовать режиму магазина. SHOP_MODE=off оставляет доступной витрину. Для проверки используйте SHOP_MODE=test и отдельные тестовые пароли. Обновите сервис shop и конфигурацию Caddy, проверьте оплату, отмену, повтор уведомления и возврат в аккаунт. Для боевого запуска после активации магазина установите SHOP_MODE=live и боевую пару паролей, пересоздайте контейнер. Базы тестовых и реальных покупок раздельные. Первую реальную выдачу предмета и доставку чека проверьте отдельно.
