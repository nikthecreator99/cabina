# Страницы сайта для ЮKassa и покупателей (черновик, не выложен)

Четыре страницы: «О сервисе и цены», «Оферта», «Политика», «Реквизиты». Собираются скриптом из одного места,
политика берётся из `js/legal.js` (не расходится с приложением).

```bash
node server/site/pages/build.mjs           # собрать в server/site/pages/info/
node server/site/pages/build.mjs --check   # упадёт, пока остались жёлтые «[ЗАПОЛНИТЬ: …]»
```

## Что решает Никита (поля `CFG` в начале `build.mjs`)
- цена подписки (фиксированная) и срок;
- дата редакции оферты;
- что именно входит в «Премиум» (сейчас в тексте — только сохранение премиум-персонажей; ЮKassa просит, чтобы на сайте
  была именно та услуга, за которую берут деньги, и она должна уже работать).

Не выдумано: ИНН, ФИО и почта взяты из `js/legal.js` (`OPERATOR`) — они уже публичны в политике.
Возврат (10 дней, пропорционально неиспользованному сроку) и «включение не позднее суток» — мои предложения, их нужно подтвердить.

## Как выложить (когда сайт снова работает; делает Claude на Opus 5.5, Никита применяет на сервере)
1. Заполнить `CFG`, `node server/site/pages/build.mjs --check`.
2. Папку `info/` положить в корень репозитория, в `server/site/cabina-site.sh` добавить `info` в `FILES`
   (скрипт на сервере переустанавливается с проверкой sha256, как раньше).
3. В `sw.js` не отдавать `index.html` на переходы по `/info/…` (иначе установленное приложение подменит страницы).
4. Поднять версию, строка в `data/changelog.json`, `npm run test:all`.
5. Адреса для анкеты ЮKassa: сайт `https://cabina-app.ru/`, реквизиты `https://cabina-app.ru/info/rekvizity.html`.

## До приёма денег (не сделано)
- Платёжная функция в самой CABINA: пока купить Премиум нельзя, а ЮKassa проверяет, что услуга действительно есть.
- Политика и согласие: платёжный сервис ЮKassa — новый получатель данных. Нужна новая редакция политики/согласия и
  уведомление Роскомнадзора об изменениях (по правилу CLAUDE.md 1.4). Сервер хранит только «подписка до такого-то числа».
- В iOS-приложении ссылок на эти страницы и кнопки оплаты быть не должно (App Store 3.1.1).
