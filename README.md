# CABINA — PWA

Статический сайт без сервера и базы данных. Все данные пользователя хранятся в IndexedDB на его устройстве.

## Как разместить (любой статический хостинг с HTTPS)

- **Netlify Drop**: откройте app.netlify.com/drop и перетащите папку `cabina`.
- **GitHub Pages**: создайте репозиторий, загрузите содержимое папки `cabina` в корень, включите Settings → Pages → ветка `main`.
- **Cloudflare Pages / Vercel**: импорт папки как статического сайта, без сборки.

После публикации откройте адрес на телефоне:
- iPhone: Safari → «Поделиться» → «На экран „Домой“».
- Android: Chrome → ⋮ → «Добавить на главный экран».

## Состав

- `index.html`, `css/`, `js/` — приложение (без внешних библиотек).
- `sw.js` — офлайн-режим; при выпуске новой версии увеличьте `VERSION`.
- `manifest.webmanifest`, `icons/` — установка на экран с иконкой CABINA.
- `data/calendar.json` — производственный календарь (2026, 2027); обновляется отдельно от записей пользователей.
- `fonts/` — Onest и Unbounded (лицензия SIL OFL), встроены, сторонние сервисы не используются.

## Проверка

- `npm install` — один раз, ставит Playwright для браузерных тестов.
- `npm test` — расчёты и календарь; `npm run test:e2e` — сценарии в браузере; `npm run test:all` — всё.
- `npm run serve` — открыть приложение локально на http://localhost:8080.

Устройство кода, формулы и порядок выпуска версии — в `CLAUDE.md`.
